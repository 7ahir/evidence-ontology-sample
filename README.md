# Evidence Verification Ontology — Sample

A one-page, anonymized extract of the shared vocabulary behind an AI evidence-verification prototype. It gives AI agents, JSON schemas and human reviewers one meaning for "claim", "evidence" and "source".

- **[One-page PDF](Tahir_Tidjani_Evidence_Ontology_Sample.pdf)** · [HTML source](evidence-ontology-sample.html)

**Contents:** 17 of 26 core entity types plus the decision-trace audit record, the evidence-graph relationships, provenance (lineage) and human-review fields, and design rules.

**Status:** The entity names and field conventions are used in the prototype's agent prompts, JSON schemas and data models. The graph relationships are a design and are not yet implemented as a graph store. Finance-specific entity types are omitted.
